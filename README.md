# 🔧 RepairProof
### Intelligent Appliance Warranty, Repair and Predictive Maintenance Management System

**RepairProof** is a Django-based web application designed to help users manage their home appliances, track warranty periods, maintain digital purchase bills, and monitor repair history in one centralized platform.

The project aims to simplify appliance maintenance and help users avoid missing warranty deadlines.

## 🎯 Project Objectives

- Manage household appliances digitally.
- Track appliance warranty expiration dates.
- Store and access purchase bills.
- Maintain appliance repair records.
- Provide maintenance insights to users.
- Reduce manual record keeping.

## ✨ Key Features

The following features are planned for the project:

- **User Authentication:** Secure registration and login.
- **Appliance Management:** Add, view, update, and delete appliance details.
- **Warranty Tracking:** Monitor active, expiring, and expired warranties.
- **Digital Bill Storage:** Upload and access purchase bills.
- **Repair History:** Maintain records of appliance repairs and service costs.
- **Predictive Maintenance:** Generate maintenance insights using appliance repair history.
- **Dashboard & Reports:** View appliance statistics and maintenance information.
- **Email Notifications:** Receive warranty expiry reminders.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Harinikanagaraju/RepairProoff.git
```

### 2. Navigate to the Project Folder

```bash
cd RepairProoff
```

### 3. Install Django

```bash
python -m pip install django
```

### 4. Apply Migrations

```bash
python manage.py migrate
```

### 5. Run the Development Server

```bash
python manage.py runserver
```

### 6. Open in Browser

```text
http://127.0.0.1:8000/
```
